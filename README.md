# 🚖 Uber Trip Data Analysis

A complete **Exploratory Data Analysis (EDA)** project on Uber trip booking data using **Python, Pandas, NumPy, and Matplotlib**. This project analyzes booking trends, ride performance, payment methods, vehicle usage, customer behavior, and generates business insights through data visualization.

---

## 📌 Project Overview

The objective of this project is to analyze Uber trip booking data to identify meaningful patterns and business insights. The project includes:

- Data Loading
- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insights

---

## 🎯 Objectives

- Analyze Uber booking data.
- Understand customer booking behavior.
- Identify the most popular vehicle types.
- Analyze booking status and cancellations.
- Study payment method preferences.
- Find peak booking hours and busiest days.
- Generate business insights from the data.
