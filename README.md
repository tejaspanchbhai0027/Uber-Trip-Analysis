# Uber Trip Analysis

This project contains an Uber trip data analysis performed in a Jupyter notebook.

## Contents

- `Uber_Trip_Analysis.ipynb` - notebook with data loading, cleaning, exploratory analysis, visualizations, and business insights.
- `uber.csv` - dataset used by the notebook.
- `requirements.txt` - Python package requirements.

## Requirements

Install the required packages before running the notebook:

```bash
pip install -r requirements.txt
```

## How to run

1. Open `Uber_Trip_Analysis.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
2. Ensure `uber.csv` is in the same folder as the notebook.
3. Run all cells to reproduce the analysis and visualizations.

## Notes

- If the dataset is large or private, consider removing `uber.csv` from the repository and replacing it with a sample dataset or download instructions.
- The notebook uses `pandas`, `numpy`, and `matplotlib`.
